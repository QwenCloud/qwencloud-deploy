# Database Identification (Step 5)

Determine whether RDS is needed based on `db_signals` from step 3 project analysis.

---

## Decision Logic

| Signal | Action |
|--------|--------|
| MySQL signal (`mysql`/`mysql2`/`sequelize`/`typeorm`/`prisma` + mysql) | AskUserQuestion: Create RDS / Skip (self-configure) |
| Non-MySQL database (postgres/redis/mongo etc.) | Inform user: only MySQL RDS is auto-orchestrated; others need self-configuration |
| No database signal | Skip this step, proceed to step 6 |

---

## Fetch live available classes

When the user chooses to create RDS, the class is picked from what is actually available in the
current region. This step precedes instance-type selection, so no zone is fixed yet: first list the
region's zones, then query the pay-as-you-go MySQL 8.0 classes available in each.

```bash
aliyun rds DescribeRegions --RegionId "$REGION"
```

From `Regions.RDSRegion[]` collect each `ZoneId` in `$REGION`, then per zone:

```bash
aliyun rds DescribeAvailableClasses \
  --RegionId "$REGION" --ZoneId "<zone>" \
  --Engine MySQL --EngineVersion 8.0 \
  --Category Basic --DBInstanceStorageType cloud_essd \
  --CommodityCode bards --OrderType BUY
```

From `DBInstanceClasses[]`, collect `DBInstanceClass` (class ID) and its vCPU / memory from
`DBInstanceClassInfos`; dedupe across zones.

## Denoise filter

Present only regular classes suitable for a lightweight deployment: drop oversized classes with
vCPU > 8 or memory > 16 GiB. Dedupe, sort ascending by vCPU then memory, and list every class individually.

## Present and select (AskUserQuestion)

List the classes one per line, each showing `class ID · vCPU/memory`, and let the user pick one.
Price is not shown here (step 9's live quote is authoritative).

---

## Output

- `DB_INSTANCE_CLASS`: User-selected RDS instance class (or empty = no RDS)
- `DB_PASSWORD`: Agent-generated random password (≥12 chars, special chars limited to `!@%^*+=_-`), never shown in chat

---

## Notes

- RDS is MySQL 8.0, pay-as-you-go
- Password is randomly generated by Agent, passed to `generate_template.py` via environment variable
- When user skips, they must self-configure an external database connection
